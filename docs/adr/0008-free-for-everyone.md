# ADR 0008 — The platform is free; no monetisation features

Status: accepted · 2026-10-02

## Decision
REGA is free for users and businesses. The code and data contain no prices for the platform, plans, subscriptions, paid
or promoted placements, checkout or payment integrations; none will be built. The terms and Impressum say so, and a test
fails if the terms mention prices or payment features. A business's own service prices remain that business's data.

## Consequences
Ranking never depends on money. Funding is outside the software.
