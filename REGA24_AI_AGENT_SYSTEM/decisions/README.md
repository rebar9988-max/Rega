# Architecture Decision Records

Record material AI/Agent architecture decisions here using numbered files (for example, `0001-reuse-existing-ai-gateway.md`).

Each decision should include:

- Status: proposed / accepted / rejected / superseded
- Context and evidence
- Decision and alternatives considered
- €0 cost verification
- Security, privacy, and permission implications
- Consequences and rollback/exit strategy

Do not record assumptions as accepted decisions. Link to the relevant pull request and tests when available.
